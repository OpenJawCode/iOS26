# docs/

Project documentation. `adr/` = decision records (template + index in `adr/README.md`). `conventions.md` = coding rules. `testing.md` = three-tier strategy. `ci.md` = CI/CD contract. Logs (`logs/`) are gitignored operational truth (bugs, mistakes, handoffs).

Owner: doc-owner. Rules: CONTEXT.md is the glossary + decision index; docs must describe reality at every phase exit (ROADMAP cross-phase invariants).
